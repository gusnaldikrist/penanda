# Code Style Guidelines

- **General**: Gunakan penamaan variabel dan fungsi yang deskriptif. Hindari singkatan yang membingungkan.
- **JavaScript / TypeScript**: 2-space indent, gunakan const/let, hindari var.
- **Python**: 4-space indent, ikuti PEP 8, gunakan type hints jika memungkinkan.
- **Comments**: Tulis komentar ringkas hanya pada logika yang kompleks.
