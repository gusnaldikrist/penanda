# Git Convention

- **Format Commit**: Conventional Commits (`feat:`, `fix:`, `refactor:`, `docs:`, `chore:`).
- **Branching**: `feat/nama-fitur`, `fix/nama-bug`.
- **Atomic Commits**: Satu commit untuk satu perubahan logis.
- **Safety**: Jangan lakukan force push ke branch utama (`main`/`master`).
